| Событие | Когда отправляется | Параметры |

| page_view | Открытие любой страницы | page_location, page_title |
| scroll | Прокрутка страницы до 90 % | percent_scrolled |
| click | Переход по ссылке на внешний сайт | link_url, outbound |
| file_download | Скачивание PDF с сайта | file_name, file_extension |
| form_start | Первое взаимодействие с формой заявки | form_id |
| form_submit | Отправка формы заявки | form_id |
| generate_lead | Отправка заказа | lead_item_id, lead_zone, value, currency |
| cta_click | Клик по любой кнопке заявки | button_name, page_section |
| catalog_filter | Изменение фильтра каталога | filter_type, filter_value_min, filter_value_max, filter_color |
| select_item | Кнопка «Заказать» у букета | items, currency, value |
| bouquet_build | Изменение состава в конструкторе | stems_count, wrap_type, total_price |
| delivery_calc | Расчёт доставки | delivery_zone, delivery_price |
| promo_copy | Копирование промокода | promo_code |
| contact_click | Клик по телефону или e-mail | contact_type |
| messenger_click | Клик по кнопке Telegram или WhatsApp | messenger |
| social_click | Клик по ссылке соцсети на thanks.html | network |
